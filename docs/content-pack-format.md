# 内容包格式说明（投稿玩家版）

一个内容包 = 一份 `project.json`，包含**世界书条目**（告诉 AI 演什么）和可选**正则**（把输出变好看 / 播放 BGM / 渲染面板）。安装后由宿主脚本自动写进角色卡，玩家可一键卸载/更新。

## 一、最小结构

```json
{
  "name": "内容包名称",
  "version": "1.0.0",
  "tags": ["事件"],
  "description": "一句话简介",
  "worldbookEntries": [ …世界书条目… ],
  "regexEntries": [ …可选：正则… ]
}
```

**tags 只能选**：`事件` / `角色包` / `材料本` / `扩展`（可多选）。
**version** 必须是 `x.y.z` 格式（如 `1.0.0`），用于更新判断。

## 二、世界书条目字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `comment` | 是 | 条目名（不用加前缀，安装器自动加 `[伊瑟利亚工坊][类别][包名]`） |
| `content` | 是 | 正文（AI 会读到的内容） |
| `key` | 建议 | 触发关键词数组，如 `["失乐园"]` |
| `keysecondary` | 否 | 次关键词数组 |
| `selectiveLogic` | 否 | 0=任一匹配，1=全部匹配 |
| `constant` | 否 | true=蓝灯常驻（如 BGM 控制器/规则） |
| `selective` | 否 | true=关键词触发（默认 true） |
| `position` | 否 | 0=角色前，1=角色后 |
| `depth` | 否 | 注入深度：入口/信息/本体/规则用 4，物品/工具用 1 |
| `order` | 否 | 排序，默认 100 |
| `useProbability` / `probability` | 否 | 触发概率，默认 100 |
| `excludeRecursion` / `preventRecursion` | 否 | 防递归，建议 true |
| `content` 中的 MVU 代码 | 否 | 用 `<%_ getMessageVar('stat_data.事件.阶段', {defaults:''}) _%>` 等读写变量，实现状态机 |

## 三、正则条目字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `scriptName` | 是 | 正则名称（安装后加 `[伊瑟利亚工坊] 包名 - ` 前缀） |
| `findRegex` | 是 | 匹配正则，如 `/【异典播放器[:：]?\s*([^【】]*?)】/gi` |
| `replaceString` | 否 | 替换内容（可用 `$1` 引用捕获组；可放 ` ```html … ``` ` 渲染界面） |
| `markdownOnly` | 否 | true=仅显示替换，不进 AI 提示词（默认 true） |
| `placement` | 否 | 作用位置：`[2]`=AI 消息，`[1,2]`=全部 |
| `maxDepth` | 否 | 最大深度限制（工具类用 1） |

## 四、事件类条目套路（参考示例包）

```
入口条目：检查"已完成事件"数组 → 未完成才触发 → 初始化 事件.标题/开启/阶段
本体条目：if (事件.标题 == '包名') → 当前阶段的分幕演出 → 阶段结尾 Json Patch 更新变量
规则条目：if (事件.标题 == '包名') → 分支跳转/拒绝处理/禁剧透
```

常用变量路径（需角色卡支持 MVU）：
```
stat_data.事件.标题 / .开启 / .阶段 / .结束 / .已完成事件
```

阶段结尾更新变量的写法（正文里写给 AI 看）：

```
当本阶段充分展开后，必须马上以 Json Patch 更新以下变量（IMPORTANT: 该变量不可见，必须按要求更新！）：
- 将"事件.阶段"的值设置为 "下一阶段名"
```

## 五、提交与审核

1. 在工坊「投稿创作」页粘贴 `project.json` 全文（或由工具生成）；
2. 填写名称、作者署名、简介、标签；
3. 提交后状态为**待审核**，工坊主在后台通过后自动上架；
4. 被打回时，投稿记录会带打回理由，按理由修改后重新投稿即可。

## 六、红线（会被打回）

- 内容包不得包含真实个人信息、恶意代码、侵权内容；
- 单条正文不超过 5 万字，条目总数不超过 200 条，正则不超过 50 条；
- 版本号与名称一旦上架不要随意变更（会影响玩家更新判断）；
- 未经允许，不得使用他人作品或"命定之诗"创意工坊的既有内容。
