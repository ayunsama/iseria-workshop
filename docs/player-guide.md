# 伊瑟利亚创意工坊 · 玩家创作指南（零基础版）

> 给完全不懂代码的玩家：照着这篇，你也能做出可以投稿的内容包。
> **强烈推荐**：你自己想点子，让 AI 工具（豆包等）帮你写。这篇指南可以直接复制给 AI 当提示词。

## 1. 内容包是什么

内容包 = **给 AI 的剧本（世界书条目）** + **给玩家的界面（正则）** + **一张名片（元信息）**。

- 世界书条目：写进角色世界书，告诉 AI 怎么演（触发时机、剧情、规则）。
- 正则：写进角色正则列表，把 AI 输出的标记变成好看界面（播放器条、面板、按钮）。
- 元信息：名称、版本（必须 1.0.0 这种格式）、标签（事件/角色包/材料本/扩展）、描述。

玩家安装 = 世界书条目并进主世界书 + 正则加进正则列表。

## 2. 开始前：找 AI 帮手（推荐）

把下面这段直接发给豆包等 AI 工具：

> 我想为「伊瑟利亚大陆」角色卡投稿创意工坊内容包。请按「伊瑟利亚创意工坊玩家创作指南」帮我创作：先问我 2~3 个问题（类型/剧情/体验），然后按五步法产出，最后给我一个 .json 文件并解释每部分是什么。

然后回答它的提问就行。AI 会帮你拆条目、写正文、拼 JSON。

## 3. 五步法（AI 会带你走，人话版）

1. **定想法**：一句话说清"玩家会遇到什么"。
2. **拆条目**：切成 2~4 条世界书——入口（怎么触发）、本体（演什么）、规则（不许做什么）、需要时加角色信息/结算。
3. **写正文**：写"给 AI 的指令"：触发条件 + 分几步演 + 边界禁忌 + 不替玩家做选择。
4. **加正则**：想要播放器/面板/按钮效果时加一条；不需要就跳过。
5. **打包投稿**：AI 生成 .json，你去工坊投稿页上传。

## 4. 投稿

1. 打开 https://iseria-workshop.1020803065.workers.dev ，切到「投稿」页签。
2. 填名称/作者/描述，上传 .json 文件，提交。
3. 状态「待审核」→ 工坊主通过后自动上架 → 玩家可安装。
4. 被打回会附原因，改完重新投。

## 5. 常见问题

| 问题 | 怎么办 |
|---|---|
| JSON 解析失败 | 让 AI 重新打包，或找在线 JSON 校验工具检查 |
| 同名投稿被拦 | 换名字，或等审核完再投 |
| 版本号不对 | 用 1.0.0 这种 x.y.z 格式 |
| 标签只能选四种 | 只用：事件 / 角色包 / 材料本 / 扩展 |
| 想做得更复杂（阶段推进、结局结算） | 让 AI 参考"失乐园"的写法（事件状态机 + 变量更新） |

## 6. 给想进阶的玩家

第一次先做 2~3 条的小事件跑通全流程；熟练后可以让 AI 帮你做带阶段推进、好感/道具结算的复杂事件包（参考失乐园：入口→阶段剧情→结局→记录完成）。
